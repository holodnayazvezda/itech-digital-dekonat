# Работа с проектом

1. Начни с корневого README, затем прочитай `solution/README.md`, `solution/client/README.md` и `solution/server/README.md`.
2. Рабочее приложение находится в `solution/`. Клиент: Vue Router, React и Vite. Сервер: Python, FastAPI, JWT и SQLCipher. Не возвращай старые прототипы.
3. Документация модулей и форматов находится в `solution/docs/`. Ссылки на актуальные макеты — в `solution/design/README.md`.
4. Не сохраняй настоящие ключи, пароли инфраструктуры, пользовательские базы и настройки развёртывания в Git. Публичные демо-доступы для жюри описаны отдельно в документации приложения.
5. Все учебные данные и пользователи демонстрационные. Сохраняй серверную авторизацию и изоляцию данных разных пользователей.
6. Проверяй изменения соразмерно задаче. Не запускай глубокую ревизию всего проекта без запроса пользователя.
7. Собственную лицензию проекта не добавлять. Уведомления о лицензиях сторонних библиотек, моделей и шрифтов сохранять.
