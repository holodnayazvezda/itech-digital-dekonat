# Атлас кампуса

Конкурсное веб-приложение «Цифровой деканат будущего». Студент видит расписание, успеваемость, учебный план и выплаты, оформляет документы и брони, общается с преподавателями. Преподаватель работает со своими занятиями и группами. Деканат ведёт обращения, письма и задачи. Учебные сведения, люди и планы корпусов вымышлены.

## Архитектура

Браузерный клиент использует Vue 3 и Vue Router для оболочки и адресов страниц, React для экранов, Preact Signals для состояния и Vite для сборки. Самостоятельный Python API на FastAPI проверяет права, хранит изменения в SQLCipher и публикует OpenAPI со Swagger. Собранный клиент и API могут обслуживаться одним процессом `server.web:app`.

Браузер получает серверное время, выполняет вход и загружает личное состояние с JWT. Заявления, брони, переписка и изменения занятий проходят через API. Подтверждённые операции сохраняются в транзакциях. Уведомления доставляются через SSE и Web Push, резервное обновление кабинета выполняется опросом API.

## Запуск и документация

Для локальной работы нужны Node.js 24 и Python 3.13. Из `solution/` установите зависимости и выполните `npm run dev`. Клиент откроется на http://127.0.0.1:4197, API и Swagger — на порту 8000.
